**Update project documentation:**

## Workflow

### Step 1: Analyze Current State
- Read existing documentation
- Scan codebase for changes
- Identify documentation gaps

### Step 2: Identify Updates Needed

**Check each doc:**
- README.md - Still accurate?
- API docs - Endpoints current?
- Architecture docs - Up to date?
- Comments - Match code?

### Step 3: Update Documentation

**README.md Updates:**
- Installation steps correct?
- Usage examples work?
- Dependencies listed?
- Links working?

**API Documentation:**
- New endpoints documented?
- Parameters accurate?
- Response formats current?
- Examples valid?

**Code Comments:**
- Complex logic explained?
- Public APIs documented?
- Deprecated items marked?

### Step 4: Report

```markdown
## Documentation Update

### Files Updated
| File | Changes |
|------|---------|
| README.md | Updated installation section |
| docs/api.md | Added new endpoint |

### Summary
- Added: [N] new sections
- Updated: [N] existing sections
- Removed: [N] outdated sections

### Remaining Gaps
- [ ] [Gap 1]
- [ ] [Gap 2]
```

## Documentation Checklist

- [ ] README has quick start
- [ ] Installation steps work
- [ ] Examples are tested
- [ ] API is fully documented
- [ ] Architecture is current
- [ ] Contributing guide exists
